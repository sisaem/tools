PDF 암호는 두 종류다

PDF 규격에는 성격이 다른 암호가 두 가지 있습니다.

열람 암호권한 암호
다른 이름사용자 암호, 문서 열기 암호소유자 암호, 편집 암호
언제 묻나파일을 열 때열 때는 묻지 않음
하는 일암호 없이는 내용을 볼 수 없게 함인쇄, 글자 복사, 편집 같은 작업을 막음
흔한 예카드·급여 명세서, 보험 증권배포용 보고서, 전자책

열람 암호가 걸린 파일은 내용 자체가 암호화되어 있어서, 암호를 모르면 어떤 도구로도 정상적으로 열 수 없습니다. 반면 권한 암호만 걸린 파일은 누구나 열어 볼 수 있고, 뷰어가 "이 문서는 인쇄를 허용하지 않습니다" 같은 제한을 따르는 방식입니다.

이 사이트에서 할 수 있는 것과 없는 것

이 사이트의 암호 관리 도구는 오픈소스 PDF 처리 프로그램인 qpdf를 브라우저에서 돌려 작업합니다. 할 수 있는 일은 두 가지입니다.

  • 암호를 알고 있는 파일의 암호 제거. 파일을 올리면 암호를 묻고, 맞는 암호를 넣으면 암호 없는 사본을 만들어 줍니다. 매달 같은 비밀번호로 오는 명세서를 보관용으로 정리할 때 쓰기 좋습니다.
  • 새 암호 설정. 4자 이상의 암호를 정하면 AES-256 방식으로 암호화한 사본을 만듭니다. 여러 파일에 같은 암호를 걸 수도 있고, 파일마다 다른 암호를 걸 수도 있습니다.

모르는 암호를 알아내거나 우회하는 기능은 없고, 앞으로도 만들 계획이 없습니다. 남이 보호해 둔 문서를 여는 일은 권한 문제이기도 하고, 열람 암호는 원리적으로 추측 말고는 풀 방법이 없기 때문입니다. 암호를 잊은 본인 문서라면 문서를 보낸 곳(카드사, 회사 인사팀 등)에 다시 받는 쪽이 빠릅니다.

받은 문서의 암호가 맞지 않을 때

정확한 암호를 넣었는데도 틀렸다고 나올 때 자주 보는 원인은 다음과 같습니다.

  1. 생년월일 자릿수. 명세서 암호를 생년월일로 안내하는 곳이 많은데, 여섯 자리(901231)인지 여덟 자리(19901231)인지 기관마다 다릅니다. 안내 메일 본문을 다시 확인해 보세요.
  2. 한/영 전환 상태. 한글 입력 상태에서 영문 암호를 치면 글자가 전혀 다르게 들어갑니다. 암호 칸에 입력한 글자는 보이지 않으니 메모장에 한 번 쳐 보고 복사해 넣는 것도 방법입니다.
  3. 앞뒤 공백. 메일에서 암호를 복사할 때 끝에 공백이 같이 딸려 오는 경우가 있습니다.
  4. 다른 방식의 보호. 일부 기업용 문서는 PDF 표준 암호가 아니라 별도의 문서 보안 프로그램(DRM)으로 잠겨 있습니다. 이런 파일은 전용 뷰어로만 열리고, 일반 PDF 도구로는 처리되지 않습니다.

암호를 걸어 보낼 때

암호를 거는 목적은 파일이 엉뚱한 사람에게 갔을 때도 내용을 지키기 위해서입니다. 그 목적을 생각하면 몇 가지 원칙이 나옵니다.

  • 파일과 암호를 같은 통로로 보내지 않습니다. 메일에 파일을 붙이고 본문에 암호를 적으면, 메일을 잘못 보냈을 때 아무 의미가 없습니다. 파일은 메일로, 암호는 문자나 메신저로 따로 보내세요.
  • 너무 짧은 암호는 피합니다. 이 도구는 4자부터 허용하지만, 숫자 네 자리는 경우의 수가 1만 개뿐입니다. 받는 사람이 쉽게 알 수 있으면서 남은 추측하기 어려운 값을 고르거나, 열 자 이상의 무작위 암호를 쓰세요. 유틸리티 도구의 임시 비밀번호 생성을 쓰면 편합니다.
  • 암호를 건 원본은 따로 보관합니다. 암호를 걸고 나면 본인도 암호를 잊었을 때 열 수 없습니다.

"브라우저에서 처리한다"는 말의 정확한 뜻

이 사이트의 PDF 도구는 파일을 서버로 올리지 않습니다. 페이지를 열 때 처리 프로그램(qpdf, pdf-lib, pdf.js 등)을 내려받고, 파일 처리는 이용자의 컴퓨터 안에서 이루어집니다. 그래서 인터넷 연결이 느려도 처리 속도는 컴퓨터 성능에 달려 있고, 처리 중인 파일이 사이트 운영자에게 전달되지 않습니다.

그렇다고 위험이 전혀 없다는 뜻은 아닙니다. 다음은 이용자 쪽에서 관리해야 하는 부분입니다.

이용자 쪽에 남는 위험

  • 공용 컴퓨터의 다운로드 폴더. 암호를 푼 파일은 다운로드 폴더에 그대로 남습니다. PC방이나 회사 공용 PC에서는 작업 후 지워 주세요.
  • 브라우저 확장 프로그램. 페이지 내용을 읽을 수 있는 권한을 가진 확장 프로그램은 이론적으로 처리 중인 데이터에 접근할 수 있습니다. 민감한 문서는 확장 프로그램을 끈 창(시크릿 창 등)에서 작업하는 편이 안전합니다.
  • 광고와 외부 스크립트. 이 사이트는 광고를 게재하며, 광고 스크립트는 파일 내용에 접근하지 않지만 방문 기록 같은 정보는 수집할 수 있습니다. 자세한 내용은 개인정보처리방침에 적어 두었습니다.

회사 보안 규정상 외부 사이트에서 문서를 다루는 것 자체가 금지된 경우도 있습니다. 그런 경우에는 규정을 따르는 것이 우선입니다.

권한 암호만 걸린 파일은?

열 때 암호를 묻지 않고, 인쇄나 복사만 막혀 있는 파일이라면 이 도구의 해제 기능에서 암호를 비워 둔 채 처리해도 되는 경우가 있습니다. 다만 그 제한은 문서를 만든 쪽이 의도해서 건 것입니다. 본인이 만든 문서이거나 작성자에게 허락을 받은 경우에만 제한을 푸세요.
